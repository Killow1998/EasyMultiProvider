BEFORE YOU START

几件值得先知道的事。

ChatGPT 登录文件在哪里？

通常是已登录 Codex 的用户目录下 .codex/auth.json。自定义 CODEX_HOME 时使用对应目录。EMP 支持 JSON 登录文件及重命名的备份文件。它包含凭据，只应导入你信任的本机 EMP，不要公开上传。

添加账号后，需要重新打开 Codex 吗？

先看接入状态。账号已保存和模型目录已加载是两件事。如果界面提示目录待加载，完成活动对话后再重新打开 Codex；如仍未加载，请手动检查目录并查看诊断。本版不承诺零重启。

关闭管理页，会退出 EMP 吗？

不会。关闭浏览器页只是收起管理界面，EMP 进程继续运行。需要退出时，使用明确的“退出 EMP”操作。本轮没有桌面窗口或托盘。

如何恢复原生 Codex？

先完成活动对话并关闭 Codex，再在接入详情里选择“恢复原生并退出”。原版后端尝试处理历史和恢复配置后停止。界面显示“停止中”或断开连接，不等于已经验证恢复成功；需要查看进程与日志，再打开 Codex 确认。

已有账号的 ID 和路由会改变吗？

不会迁移或重写已有 ID、别名、前缀或绑定。新账号可以先填昵称，前端为技术标识提供无冲突的默认值。具体模型仍由你在 Codex 中选择。
