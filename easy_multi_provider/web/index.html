Codex Subscription Accounts

服务仅监听本机；账户 Token 只写入本机加密目录，不会返回到浏览器，也不会写入 config/catalog。

导入时只需要填写账户 ID；显示名称和模型前缀默认使用账户 ID，可在列表中编辑。重复账户不会生成重复订阅模型，但不会自动删除加密凭据。

EMP 迁移包包含配置、模型、Provider key 和订阅凭据；导出时设置迁移密码，导入到其他设备后会重新写入该设备自己的加密存储。

Providers

点击添加后选择官方 Provider 或自建 Provider。官方 Provider 自动填写固定地址和协议；自建 Provider 可以使用自动协议检测。

Models / 路由

模型只会在 Provider 的“拉取模型”中选择导入；导入后按 Provider 分组，最新模型优先，隐藏模型排在最后。
