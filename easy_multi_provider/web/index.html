Codex Subscription Accounts

服务仅监听本机；账户 Token 只写入本机加密目录，不会返回到浏览器，也不会写入 config/catalog。

导入后会自动检查是否与当前 Codex 登录或其他已导入账户重复；重复副本不会出现在生成的订阅模型列表中，但不会自动删除加密凭据。

余量显示示例：

19%/7d MMDD-HHmm (UTC-7)
99%/5h MMDD-HHmm (UTC-7)

Providers

Models / 路由
