Codex Subscription Accounts

服务仅监听本机；账户 Token 只写入本机加密目录，不会返回到浏览器，也不会写入 config/catalog。

导入时只需要填写账户 ID；显示名称和模型前缀默认使用账户 ID，可在列表中编辑。重复账户不会生成重复前缀模型；与当前 Codex 登录重复时，账户的模型显示设置将直接控制原生模型列表。

EMP 迁移包包含配置、模型、Provider key 和订阅凭据；导出时设置迁移密码，导入到其他设备后会重新写入该设备自己的加密存储。
