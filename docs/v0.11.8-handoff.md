# v0.11.8 development handoff

The local source version is 0.11.8. The latest published release remains
0.11.7. This file preserves the next tasks for the post-restart model session.

## Completed before restart

- Added a distinct pie-style icon to **Usage & estimates**.
- Kept the 0.11.7 Codex 0.156 model, Free-plan 30-day quota, and quota-trend
  fixes in the 0.11.8 source baseline.

## Next tasks

1. Simplify **Model display**: remove **Show all / Collapse**, render every
   search match, remove the explicit **Save** button, and persist display-name
   and context changes automatically. Serialize or snapshot automatic saves so
   rapid edits cannot overwrite each other. Preserve **Advanced** behavior.
2. Reproduce the Xubuntu Firefox import failure for both `.emp` and
   `auth.json`. The failure appears after a file is chosen and the page reports
   that it cannot write; changing the selected file to mode `777` did not help.
   Compare Firefox with Chrome, inspect the browser request and EMP JSONL log,
   and determine whether `xdg-desktop-portal-gtk`, browser sandboxing, or the
   EMP import endpoint is responsible. Test source and packaged launches.
3. Make Linux installation choices explicit. Debian packages are system-owned
   and install `/usr/bin/EMP` through privileged `apt`; they cannot reliably
   target the invoking user's `$HOME`. The tar installer owns the user-scoped
   flow and creates `~/.local/bin/EMP`, which supports EMP's web updater.
   Improve release/UI guidance so users can choose this path without confusion.
4. Review Linux launch behavior together with task 3: document when a desktop
   launch intentionally has no terminal and ensure source/user installs expose
   enough startup and recovery information when the browser does not open.

## Relevant observations

- The reproduced server was `127.0.0.1:4200`.
- A second source launch failed at `listener_bind` because another EMP already
  owned the port; this is separate from the import failure.
- Firefox could not reuse a copied authenticated link while Chrome worked in
  the reported session. The one-use bootstrap gate was subsequently removed in
  commit `cb1a455`; verify current behavior before attributing a new failure to
  browser cookies.
- The user-level Linux installer is `packaging/install-user.sh`; the Debian
  builder intentionally stages the executable at `/usr/bin/EMP`.
